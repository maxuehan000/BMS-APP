EPROM映射和定义

    1. 地址0x00 ~ 0x1F中的EPROM数据用于IC供应商内部使用，不允许对这些寄存器进行写入或编程。
    2. 地址0x20~0x3F中的EPROM数据用于电池组系统设计选项。在上电复位期间或在定义的条件下通过数据映射操作将数据映射到寄存器0xE0~0xFF。
    3. 对于与参数选项表中的项目对应的EPROM数据位，在解释其含义时，首先给出参数选项表的项目名称

配置0: 0x20,寄存器地址 0xE0

    1. ovp_dly[2:0]：基于ADC的OV延迟时间，（2N2.+2），2~16个扫描周期，步长=2。
    2. ovp_rls_hys[4:0]：常温下OV释放的滞后电压，范围为10mV~630mV，20mV/步。
    3. ovp_th[7:0]：常温状态下基于ADC的OV保护阈值，范围为2.57V~5.11V，10.0mV/step。通过ovp_th[7:0]=8'd0可以禁用该功能

配置1: 0x21,寄存器地址 0xE1

    1. uvp_dly[3:0]：基于ADC的UV延迟，（2N+2），2~32个扫描周期，步长=2。
    2. uv_rls_hys[4:0]：欠压释放的滞后电压，范围为20mV~1.26V，40mV/步。
    3. uvp_th[6:0]：欠压防护阈值，范围为1.0V~3.52V，20.0mV/step。该功能可以通过uvp_th[6:0]=7'd0来禁用。
   
配置2: 0x22,寄存器地址 0xE2

    1. doc1p_th[7:0]：DOC1保护的阈值，范围为 1.0mV~255mV，1.0mV/step。该功能可以通过doc1p_th[7:0]=7'd0禁用。
    2. cocp_th[7:0]：COC保护的阈值，范围为1.0mV~255mV，1.0mV/step。可通过cocp_th[7:0]=7'd0禁用该功能。

配置3: 0x23,寄存器地址 0xE3

    1. doc2p_dly_unit[2:0]：000～111:1ms、2ms、4ms、8ms、16ms、31.25ms、62.5ms、125ms。
    2. doc2p_dly[3:0]：doc2p延迟时间，（N+1）x doc2p_dry_unit[2:0]。
    3. scp_th[3:0]：短路保护阈值。范围为50mV~500mV，30mV/步。
    4. doc2p_th[3:0]：放电超过电流水平2（DOC2）阈值。范围为20mV~320mV，20mV/步

配置4: 0x24,寄存器地址 0xE4

    1. cocp_dly[2:0]：基于ADC的cocp延迟，（2N+2），2~16个扫描周期，步长=2。
    2. doc1p_dly[4:0]：基于ADC的doc1p延迟，（2N+2），2~64个扫描周期，步长=2。
    3. chg_th[3:0]：充电电流阈值，感测电阻器上的范围为0.125mV~2.0mV，0.125mV/step。
    4.  dsg_th[3:0]：放电电流阈值，感测电阻器上的范围为0.125mV~2.0mV，0.125mV/step。
   
配置5: 0x25,寄存器地址 0xE5

    1. ot_dly[2:0]：延迟DOT/COT的扫描周期（2N+2），步长=2。
    2. dotr_hys[4:0]：DOT释放滞后，范围为5mV~160mV，5mV/步。
    3. dot_th[7:0]：dot阈值（小于~640mV），2.5mV/步。通过设置dot_th[7:0]=8'd0可以禁用此功能
配置6: 0x26,寄存器地址 0xE6

    1. ut_dly[2:0]：延迟DUT/CUT的扫描周期（2N+2），步长=2。
    2. cotr_hys[4:0]：COT释放滞后，范围为5mV~160mV，5mV/步。
    3. cot_th[7:0]：cot阈值，范围为0~1275mV，5mV/步。通过设置cot_th[7:0]=8'd0可以禁用此功能
配置7: 0x27,寄存器地址 0xE7

    1. scp_dly[1:0]：SC延迟确认时间，“00”：62.5us，“01”：125us，“10”：250us，“11”：500us。
    2. dutr_hys[4:0]：DUT释放滞后，2.5mV/步。
    3. dut_th[8:0]：dut阈值，范围为1280~2557.5mV，2.5mV/步。基极为1280mV，对应于9'd0。通过设置dut_th[8:0]=9'd0可以禁用此功能。
配置8: 0x28,寄存器地址 0xE8

    1. cutr_hys[4:0]：CUT释放滞后，范围为2.5mV~80mV，2.5mV/step。
    2. cut_th[8:0]：切割阈值，范围为1280~2557.5mV，2.5mV/步。基极为1280mV，对应于9'd0。通过将cut_th[8:0]设置为9'd0，可以禁用此功能。
配置9: 0x29,寄存器地址 0xE9

    1. 0v_chg.prohibit_th[3:0]：如果满足检查条件时最小电池电压低于此阈值，将禁止充电。范围为0.16V~2.4V，160mV/步。此功能可以通过设置零来禁用。延迟时间平均分配。滞后固定为50mV进行释放。
    2. 0v_set_in_sleep：该选项用于在长时间睡眠期间出现0v的情况下禁止唤醒后充电。'1'：如果启用了0V功能，则在睡眠期间将设备设置为0V状态，唤醒后，第一次扫描将检查是否存在真正的0V，如果不存在，将释放此0V状态以允许充电，否则不允许充电并保持此状态（需要维修电池组）；'0'：没有此功能。
    3. out1_type:“0”：配置开漏输出，“1”：配置推挽输出。
    4. out2_type:“0”：配置开漏输出，“1”：配置推挽输出。
    5. out1_sel:“1”：配置out1作为数字输出函数，“0”：配置out 1作为thm3函数



0x62 中断标志

    1. porn_flag：（R/C），当上电复位发生时设置为1（无屏蔽中断，即始终启用），通过向该位写入1将其清除为0。0v_flag：（R/C），当确认0v充电禁止时设置为2，通过向此位写入1清除为0。
    2. eoc_flag：（R/C），当检测到充电结束时设置为1，通过向该位写入1将其清除为0。
    3. iotp_flag-（R-C），当确认内部OT时设置为2，通过向此位写入1清除为0。
    4. cut_flag：（R/C），当确认cut时设置为1，通过向该位写入1将其清除为0
    5. dup_flag：（R/C），当DUT被确认时设置为1，通过向该位写入1将其清除为0
    6. cot_flag：（R/C），当确认cot时设置为1，通过向该位写入1将其清除为0
    7. dot_flag：（R/C），确认dot时设置为1，通过向该位写入1将其清除为0
    8. cto_flag：（R/C），确认cto时设置为1，通过向该位写入1将其清除为0
    9. ub_flag：（R/C），当ub被确认时设置为1，通过向该位写入1将其清除为0。
    10. uvp_flag：（R/C），确认UV时设置为1，通过向该位写入1将其清除为0
    11. ovp_flag：（R/C），确认OV时设置为1，通过向该位写入1将其清除为0
    12. cocp_flag：（R/C），确认COC时设置为1，通过向该位写入1将其清除为0。
    13. doc1p_flag：（R/C），当DOC1被确认时设置为1，通过向该位写入1将其清除为0
    14. doc2p_flag：（R/C），当确认DOC2时设置为1，通过向该位写入1将其清除为0。
    15. scp_flag：（R/C），当SC被确认时设置为1，通过向该位写入1将其清除为0

0x63 状态寄存器

    1. 0v_state_in_sleep：（RO），如果配置了0v功能并且0v_set_in_sleep=1，则在睡眠期间设置为1，如果唤醒后没有0v，则清除为0。     
    2. 0v_state：（RO），当确认0v充电禁止时设置为1，释放时由硬件清除为0。
    3. eoc_state：（RO），检测到充电结束时设置为1，释放时由硬件清除为0。
    4. iotp_state：（RO），确认内部OT时设置为1，发布时由硬件清除为0
    5. cutp_state：（RO），确认CUT时设置为1，释放时由硬件清除为0。
    6. dutp_state：（RO），确认DUT时设置为1，释放时由硬件清除为0
    7. cotp_state：（RO），确认COT时设置为1，发布时由硬件清除为0。
    8. dotp_state：（RO），确认DOT时设置为1，发布时由硬件清除为0
    9. cto_state：（RO），检测到cto时设置为1，发布时由硬件清除为0。
    10. ub_state：（RO），确认ub时设置为1，发布时由硬件清除为0
    11. uvp_state：（RO），确认UV时设置为1，发布时由硬件清除为0
    12. ovp_state：（RO），确认OV时设置为1，释放时由硬件清除为0。
    13. cocp_state：（RO），确认COC时设置为1，发布时由硬件清除为0
    14. doc1p_state：（RO），确认DOC1时设置为1，发布时由硬件清除为0。
    15. doc2p_state：（RO），确认DOC2时设置为1，发布时由硬件清除为0
    16. scp_state：（RO），确认SC时设置为1，释放时由硬件清除为0

0x64 中断使能

    1.  中断启用。默认值=0，高电平激活，以在下一个寄存器中启用相应的中断源
